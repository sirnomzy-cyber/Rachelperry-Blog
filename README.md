# Rachel's Blog

A premium personal brand lifestyle blog — built with pure HTML, CSS, and JavaScript.

## 🚀 Deploy on Vercel

### Option 1 — One-click via Vercel Dashboard
1. Push this folder to a GitHub repository
2. Go to [vercel.com](https://vercel.com) → **Add New Project**
3. Import your GitHub repo
4. Vercel auto-detects it as a static site — click **Deploy**
5. Done. Your site is live. ✅

### Option 2 — Vercel CLI
```bash
npm i -g vercel
cd rachels-blog
vercel
```

## 📁 Project Structure

```
rachels-blog/

```

## ✨ Features

- 4 pages: Home, About, Recommendations, Writing & Perspective + Blog Post view
- Dark mode toggle
- Blog search & category filtering
- Scroll reveal animations
- Sticky navbar, back-to-top button
- Fully responsive (mobile, tablet, desktop)
- Newsletter signup
- Affiliate disclosure system

## 🎨 Tech Stack

- Pure HTML5, CSS3, Vanilla JavaScript
- Google Fonts (Cormorant Garamond + DM Sans)
- No frameworks, no dependencies, no build step required
